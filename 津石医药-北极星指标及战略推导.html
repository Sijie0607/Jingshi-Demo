3.3 KPI 指标金字塔

北极星指标 / North Star Metric

月度高质量受试者访视闭环数

2027年较2026基线提升30%；具体目标需基于当前月均访视量、资料缺失率、返工率确认次/月

指每月由CRC参与完成，并同时满足以下条件的受试者访视次数：1）访视在方案规定窗口内完成；2）关键源文件完成上传、脱敏、结构化与归档；3）CRC完成AI结果复核或必要修正；4）AE/SAE/CM等风险已识别并按SLA处理；5）申办方/CRA可追溯查看导出物与审计日志；6）未产生重大质量偏差或关键资料缺失。该指标把CRC日常重复劳动、现场经验判断、受试者访视质量和申办方协同体验统一到一个可量化的结果上。

核心业务策略

P0

CRC访视闭环Copilot

SWOT: W-重复录入/经验依赖 x O-AI流程自动化

围绕每日访视、待办、资料、风险、归档，为CRC提供任务优先级、异常提醒、下一步动作建议和自动归档能力，把访视执行从人工追踪升级为系统闭环。

核心动作
建立访视级任务清单与状态闭环 对访视窗口、资料缺失、AE/SAE/CM风险进行智能提醒 将口头确认、复核结论、导出物自动沉淀到审计链
支撑指标 月度高质量受试者访视闭环数 / CRC人均高质量访视闭环数
P0

源文件到申办方复核的自动化链路

SWOT: W-资料分散/手工归档 x O-文档智能识别

把病历、化验单、访视记录、AE/SAE/CM材料从上传脱敏、结构化识别、左图右表复核到导出归档做成统一链路，减少CRC重复劳动并提升申办方复核效率。

核心动作
统一受试者、访视、文档类型、导出物命名规则 强化脱敏、结构化、人工复核和审计日志 支持申办方/CRA按项目、受试者、访视追溯
支撑指标 访视资料准时完整归档率 / 申办方/CRA复核一次通过率
P1

现场风险前置预警

SWOT: W-风险识别依赖经验 x T-重大偏差/稽查风险

把风险管理从事后补救前移到访视执行中，通过过程数据识别资料缺失、访视异常、AE/SAE/CM风险和升级滞后，让项目经理、质控和申办方更早形成共同处置。

核心动作
建立访视级风险评分 对SAE、关键缺失资料、超期访视设置SLA预警 将风险处理过程转化为客户同步材料
支撑指标 AE/SAE/CM按时识别与升级率 / 关键资料返工/质疑率
P1

CRC经验沉淀与复用

SWOT: W-经验分散 x O-知识操作系统

把一线CRC在入排判断、访视异常、资料补正、AE/SAE/CM处置中的经验沉淀为可检索、可复用、可训练的知识资产，降低新人学习成本并稳定交付质量。

核心动作
沉淀入排、AE/SAE/CM、资料归档和稽查问答知识库 把典型偏差、纠偏动作、客户复核意见转化为情景案例 建立CRC能力标签和情景化训练机制
支撑指标 核心CRC年度保留率 / 关键资料返工/质疑率
