## 一、文档侧（津石医药AI规划/）

### 1. 本体设计 · `津石医药-CRC访视风险智能助手本体设计.{yaml,html}`（重写）

- **risk_signal 类型修正**：由「事件对象」改为「**核心对象**」——风险信号是系统核心产出，不是事件记录。
- **lab_indicator 角色**：检查单（source_document）1:N 记录检验指标；lab_indicator N:N 匹配 sop_rule；N:1 支撑 risk_signal。原型第 2 步的体温/ANC/PLT/ALT/肌酐均属此实体。
- 术语修正：`CRC复核证据整理` → `研究者复核 / 复核证据包`。

## 二、原型侧（津石医药CRC风险智能助手2/prototype-crc-risk-assistant/）

### 1. 右侧「对话式 AI 助手」→「结构化访视协作侧栏」
- 原右侧为受控聊天框（模拟 Agent 回复 + 关键词护栏），本轮替换为 **4 个结构化面板**，全部为预设数据、**零 LLM、零 API**：
  1. **待确认问题清单**（对应 review_packet.question_list，可勾选，回显为步骤 03 待办）
  2. **规则命中依据**（CTCAE v5.0 / SOP-CR-03 / AE-02，与第 2 步一致）
  3. **证据时间线**（source_document + lab_indicator 加工节点；数据冲突分支多出 LIS 冲突节点）
  4. **人机权限边界**（AI / CRC / 研究者各自可做与不可越过）
- 目的：规避大模型接入的复杂度与费用，保留「可追溯、不越权」价值。
- 变更文件：`src/App.tsx`（Chatbox→CollaborationPanel）、`src/data.ts`（新增 reviewQuestions / permissionBoundary / evidenceTimeline）、`src/index.css`。

### 2. 队列场景标注 MVP / 路线图
- `VisitCase` 新增 `scope` 字段；PV-031 标注 **MVP**，PV-019 / PV-044 标注 **路线图**。

### 3. 第 2 步文案对齐检验指标术语
- 解析管线改为「检验指标标准化」；抽取结果改为「5 个检验指标已抽取」；说明文案对齐 lab_indicator 口径。

### 4. 文档配套
- `README.md`：演示路径改为结构化侧栏操作，产品边界补充「无 LLM 对话接口」。
- `津石医药AI规划/CRC风险辅助Agent-MVP-Demo讲解文本.md`：整体重写为实际 5 步流程 + 结构化侧栏 + 5 条行动边界。
