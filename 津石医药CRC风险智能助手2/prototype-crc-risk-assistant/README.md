# CRC 访视风险智能助手

面向 CRC 的独立 Web 演示原型，用于展示如何把访视资料整理、AE/SAE/CM 线索预识别、医生线下确认、动作闭环与受治理反馈学习串成一条可追溯工作流。

> 本项目全部内容均为模拟演示数据，不包含真实患者信息。系统输出不是医学诊断、最终 CTCAE 定级、SAE 判定或 EDC 自动提交。

## 快速开始

```bash
npm install
npm run dev
```

生产构建与代码检查：

```bash
npm run build
npm run lint
```

## 推荐演示路径

1. 在左侧选择 `PV-031`（MVP 主场景），切换中心 CRC / CRC 组长视角。
2. 进入第 2 步，点击“载入模拟检查单”，观察解析动画与检验指标抽取。
3. 点击化验单数值或右侧指标卡，演示原文证据联动。
4. 在右侧“访视协作侧栏”勾选待确认问题清单，观察回显为医生确认步骤的待办引用。
5. 第 3 步选择医生指令模板并编辑，展示线下确认的结构化回填。
6. 第 4 步核对动作、截止时间和关闭标准，强调 EDC 仅生成草稿。
7. 第 5 步提交知识优化候选，展示 CRC 组长复核与版本发布治理链。
8. 切换“数据冲突”“资料缺失”分支，或使用“重置演示”恢复初始状态。

> 队列中的 `PV-019`、`PV-044` 标注为**路线图**场景，非本轮 MVP 主链路，仅作范围说明。

## 产品边界

- 直接用户：中心 CRC、CRC 组长。
- 医生角色：线下医学确认来源，不直接操作本工具。
- AI 能力：资料抽取、检验指标映射、候选规则命中、证据时间线、待确认问题清单、动作与 EDC 草稿。
- 右侧为**结构化访视协作侧栏**（待确认问题清单 / 规则命中依据 / 证据时间线 / 人机权限边界），全部为预设数据，不包含 LLM 对话接口。
- 人工权限：研究者负责医学判断；CRC 负责核对和回填；CRC 组长负责知识候选复核。
- 系统限制：不连接真实 API，不上传本地文件，不自动写入 EDC，不通过单次反馈修改线上 RAG。
